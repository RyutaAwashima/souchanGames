# ポポのそらたび

外部ライブラリ不要のHTML Canvas製ゲーム。ルートのゲーム一覧から起動できます。

- 画面の左・中央・右をタップすると、そのレーンへ移動して星パンチを発射します。
- ライフは6。プレイヤーの下のピンクのハートが残量、暗いハートが失ったライフです。
- ステージ1のUFOは3レーンを往復します。移動中も実際の表示位置に攻撃を当てます。
- UFOは移動の合間に「💦」で予告してから停止し、「😮‍💨」の間に攻撃のチャンスを作ります。停止中は弾を撃ちません。
- ステージ2のロボットは左右の腕、中央の頭、時間限定の弱点の順に攻撃します。
- ロボットの弱点が露出している間は「💦」でチャンスを知らせ、ボスの攻撃を止めます。
- 両ボスの通常弾・水弾の発射間隔は初期版より30%長くしています（弾速は変更なし）。
- はじめると明るい自動演奏BGMと効果音が鳴ります。右上の「おと」ボタンでいつでも切り替えられます。音声ファイルは使わず、ブラウザー内で生成します。
- ライフがなくなると、現在のステージの最初からライフ6で再開できます。
- ステージ2クリア後に「エンドレスへ」を選ぶと、2ステージを繰り返し遊べます。
- エンドレスモードでは敵を倒すとスコア+1・ハート+1、UFO撃破で+5、ロボット撃破で+10・ハート+1（ライフ上限6）。
- スコア1点ごとにゲーム進行速度が0.05倍ずつ上がり、5倍の次は速度だけ1倍に戻って上昇を繰り返します。スコアとライフは速度リセットでも維持されます。

GitHub Pagesではリポジトリのルートを公開対象にします。

回帰テストはリポジトリのルートで `node --test tests/popo-sky-trip.test.cjs` を実行します。
